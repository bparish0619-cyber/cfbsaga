# Sagarin College Football Ratings

A mobile friendly board built from Jeff Sagarin's published college football ratings (sagarin.com/sports/cfsend.htm): all 266 rated teams, five rating systems (Rating, Predictor, Golden Mean, Recent, Strong Recent), schedule strength, conference averages, his published game predictions, and a matchup predictor using his method (compare ratings, add the home advantage).

The page is a single static index.html, refreshed every Sunday at noon Central during the season and deployed to Netlify from this repo. Ratings data and method are Jeff Sagarin's, all rights his.
